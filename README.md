# Добрая весть — сайт церкви

Лендинг-сайт церкви «Добрая весть» (г. Витебск). Одностраничный сайт с навигацией по якорям, адаптивным меню и картой проезда.

## Стек

- **Vue 3** (Options API, SFC без `<script setup>`)
- **Vite 8** — сборка и dev-сервер
- **Plain CSS** с CSS-переменными (без препроцессоров и UI-фреймворков)
- **Yandex Maps** — встраиваемая карта в секции «Контакты»

Все модули самодостаточны: каждый содержит `.vue`-компонент и свой `.css`-файл, подключаемый через `<style src="./*.css">`.

Алиас `@` указывает на `src/` (см. `vite.config.js`).

## Конфигурация контента

Весь контент сайта (название, телефон, адрес, пункты меню, CTA, соцсети) задаётся в одном файле — `src/config/site.js`. Компоненты импортируют его и рендерят данные реактивно. Чтобы поменять пункт меню или телефон — правьте только этот файл.

## Секции страницы

`App.vue` содержит hero и пустые секции-якоря: `#services`, `#schedule`, `#news`, `#about`, `#contacts`. В секции контактов динамически подгружается виджет Yandex Maps с конкретной точкой (конструктор карт).

## Команды

```bash
npm install      # установка зависимостей
npm run dev      # запуск dev-сервера Vite
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр собранной версии
```
